GitHub access token

Submitting an article triggers a GitHub Action in deanputney/read-articles. That requires a fine-grained personal access token, stored only in this browser (localStorage) — it is never sent anywhere except GitHub's API.

  1. Open the fine-grained token page →
  2. Set an expiration you're comfortable with.
  3. Under Repository access, choose Only select repositories and pick deanputney/read-articles.
  4. Under Repository permissions, set Contents to Read and write (this is what lets the form trigger the workflow).
  5. Click Generate token, copy it (starts with github_pat_), and paste it below.
Before you can submit, add a GitHub access token in ⚙ Settings (top right).

Processing takes a few minutes. Watch progress on the Actions tab.
